# NovaCalc — Calculadora científica web

Proyecto académico de **Matemáticas Discretas 02**. Calculadora científica responsiva creada con **HTML, CSS y JavaScript**, sin frameworks ni dependencias obligatorias.

## Cómo usar

1. Abrir `index.html` en un navegador moderno (Chrome, Edge o Firefox).
2. Hacer clic en las teclas o usar el teclado numérico.
3. Pulsar `=` o Enter para calcular. Escape limpia y Backspace borra.

## Funciones

- Suma, resta, multiplicación y división.
- Paréntesis, potencias y factoriales.
- Seno, coseno y tangente en grados o radianes.
- Raíz cuadrada, logaritmo decimal y natural.
- Constantes π y e.
- Interfaz adaptable a computadora y teléfono.

## Tecnologías

HTML5 · CSS3 · JavaScript ES2020.
